Проект представляет собой набор автотестов для проверки функциональности веб-приложения Stellar Burgers (сервис сборки и заказа бургеров).
Описание проекта
Тесты покрывают основные пользовательские сценарии:
Регистрация пользователя (валидные данные и ошибки валидации пароля).
Различные способы входа в аккаунт (через главную, форму регистрации, восстановление пароля).
Переходы между разделами Личного кабинета и Конструктора.
Функциональность Конструктора (переключение вкладок «Булки», «Соусы», «Начинки»).
Выход из аккаунта.
Стек технологий:
Python 3.x
Selenium WebDriver — для управления браузером.
Pytest — в качестве тестового фреймворка.
WebDriverWait (Expected Conditions) — для обработки динамических изменений элементов.


lokators.py - список всех локаторов
conftest.py -файл с фикстурами
test_enter_to_account.py - тесты на вход пользователя
test_enter_to_constructor_from_account.py - тесты на переход из личного кабинета в конструктор 
test_entrance.py - тесты для перехода в личный кабинет
test_exit_from_account.py - тесты на выход из аккаунта
test_registration.py - тесты для ркгистрации
test_section_constructor.py - тесты раздела "Конструктор"
